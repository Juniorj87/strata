# AGENTS.md — Strata

Правила для агентов, работающих в этом репозитории. Часть перенесена из глобальных
`~/.gemini/GEMINI.md` и `~/.gemini/HUMAN_ALIGNMENT.md`, часть выведена из самого кода.

## Стиль общения

- Прямо, живо, без канцелярита и «Конечно, я с радостью помогу». Суть важнее формы.
- Короткие/эмоциональные сообщения читать по смыслу, а не по буквам. Не спорить по формальностям.
- Объяснять сложное простым языком; звучать как человек, а не как чейнджлог.
- В конце работы — честный отчёт: что сделано, чем проверено, что осталось.

## Автономность

- Делать задачу целиком, а не останавливаться на плане или markdown-спеке.
- Нашёл ошибку — починить причину, перепроверить, отчитаться фактами.
- Не спрашивать разрешения на обычные шаги (правка файлов, typecheck, dev-сервер, тесты).

## Проект

- Strata — статический SPA (Vite + React 19 + React Router 7 + TypeScript, strict).
- Бэкенда нет: браузер ходит напрямую в Asentum RPC (chain `1423`), Auras AMM и индексатор.
- Контракты стратегий — JS в `contracts/`, деплой через `scripts/deploy.ts`.
- Ничего не хранить на сервере. Пользовательские данные — только `localStorage`, по владельцу.
- Не выдумывать данные: если модуль не подключён (например перпы), UI обязан это показывать явно.

## Команды

```bash
npm run dev            # vite dev-сервер
npm run typecheck      # tsc -b
npm run lint           # oxlint
npm run build          # tsc -b && vite build
npm run chain:check    # проверка связи с сетью
npm run test:trading   # симуляция жизненного цикла стратегии
```

Перед сдачей правки: `npm run typecheck` и, если менял логику, соответствующий
`test:*` скрипт. Не отключать проверки, не глушить ошибки, не ослаблять ассерты.

## Код

- TypeScript strict, функциональные хелперы в `src/lib/*`, страницы в `src/pages/*`.
- Стили — существующий `src/styles.css` и классы проекта; не тащить UI-фреймворки.
- Числа с плавающей точкой для денег не использовать там, где есть bigint/строки.
- Новые зависимости — только если в проекте нет подходящей.

## Безопасность

- Никаких ключей, сидов, API-ключей и адресов кошельков в коде. Только `.env.local` (в git не входит).
- Никакого `exec`/`execSync` со склейкой пользовательских строк — только массивы аргументов.
- Никакого `Math.random()` для безопасности и логики ставок/транзакций — только `crypto`.
- `.env*`, `logs/`, `dist/`, `backups/` не коммитить.
- Приватные ключи не логировать и не отправлять наружу; подпись — только через кошелёк пользователя.
